# Password Generator

A simple, lightweight, and secure password generator web app built with vanilla HTML, CSS, and JavaScript.

## Features

- 🔐 Generate secure passwords with customizable length (4-128 characters)
- 🎛️ Toggle character types: Uppercase, Lowercase, Numbers, Special Characters
- 📱 Responsive design that works on all devices
- 🌙 Automatic dark/light mode support
- 📋 One-click copy to clipboard
- ⚡ Fast and lightweight - no dependencies
- 🚀 Single static page - easy to deploy anywhere

## Quick Start

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Set your desired password length
4. Select which character types to include
5. Click "Generate Password"
6. Copy your secure password!

## Local Development

```bash
# Clone the repository
git clone https://github.com/your-username/password-generator.git

# Navigate to project directory
cd password-generator

# Start a local server (optional)
python3 -m http.server 8000

# Open in browser
open http://localhost:8000
```

## Deployment

This is a static web app that can be deployed anywhere:

- **GitHub Pages**: Push to GitHub and enable Pages
- **Netlify**: Drag and drop the folder
- **Vercel**: Connect your GitHub repository
- **Any web server**: Upload the files to your hosting provider

## Security

- All password generation happens locally in your browser
- No data is sent to any servers
- Passwords are not stored or logged anywhere
- Uses cryptographically secure random number generation

## Browser Support

Works in all modern browsers including:

- Firefox 55+
- Safari 11+
- Edge 79+
